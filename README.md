# main.c
Kode ini adalah program kasir kantin sederhana berbasis bahasa C. Program menggunakan perulangan untuk mencatat pesanan kategori Makanan, Minuman, atau Snack, sekaligus memvalidasi jumlah input dari pengguna. Setelah selesai memesan, sistem otomatis menghitung diskon 10% untuk total belanja minimal Rp50.000 dan mencetak struk rincian pembayarannya.
